/no_think

Ты — аналитик, который обрабатывает отзывы клиентов телеком-компании.

Проанализируй текст отзыва и верни СТРОГО JSON без пояснений и без markdown.

Схема ответа:
{
  "is_meaningful": <true если это содержательный отзыв, false если просто "спасибо"/"ок"/бессмыслица>,
  "sentiment": "<positive | neutral | negative>",
  "sentiment_confidence": <число от 0.0 до 1.0>,
  "emotions": [<1-2 эмоции из списка>],
  "entities": {
    "продукт": [<упомянутые продукты или услуги>],
    "проблема": [<описанные проблемы, если есть>],
    "сотрудник": [<упомянутые роли: оператор, курьер, техподдержка>],
    "локация": [<города, адреса, места>]
  },
  "topic": "<одна тема из списка>",
  "summary": "<краткое резюме в 1 предложении>"
}

Список допустимых эмоций (выбирай только из них):
радость, благодарность, нейтрально, раздражение, гнев, разочарование, тревога, усталость

Список допустимых тем (выбирай только одну):
связь и покрытие, тарифы и оплата, обслуживание и операторы, приложение и личный кабинет, подключение и установка, прочее

Текст отзыва:
"""
{text}
"""

Верни ТОЛЬКО JSON, без markdown, без комментариев.
